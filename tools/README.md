# tools

## md2pdf.py（レジメ → PDF）

`レジメ/*.md` が教材本文の正本で、`pdf/*.pdf` はそこから作る生成物。PDF は直接編集しない。

```
python tools/md2pdf.py --all                                        # 第16〜30回の 15 冊をまとめて作る
python tools/md2pdf.py "レジメ/第22回_Webゲームプログラミング1（ゲームループ）.md"   # 1 冊だけ作る
```

- 出力先：リポジトリ直下の `pdf/`（`.md` と同じ名前の `.pdf`）。
- Claude Code では、`レジメ/*.md` を Write / Edit すると、フック（`.claude/settings.json`）が自動で実行する。図（SVG）だけを変えたときは手動で実行する。
- 必要なもの：Python の `markdown`（`pip install markdown`）、Microsoft Edge または Google Chrome。
- PDF をビューアで開いたままにすると、上書きに失敗する。

### レイアウト

- A4 縦。各ページの下に教材タイトルと「ページ番号 / 総ページ数」。
- コードは行の境目で改ページする。30 行以下のコードはできるだけ 1 ページに収め、長いコードはページをまたぐ（最初と最後の 2 行は離さない）。
- 長いコード行は折り返し、続きは元のインデントより 2 文字右から始める。右端は切れない。
- コードの直前の説明・見出しだけがページの最後に残らないようにする。図・表の直前の説明も同じ。
- 8 行以下の表は 1 ページに収める。長い表は行の境目で改ページし、見出し行をくり返す。短いセルは折り返さない。
- 画像は `<base>`（レジメのフォルダ）で `images/lessonNN/...` を読み込む。ページからはみ出さないように縮める。
- 入れ子の箇条書き（2 文字の字下げ）は、変換のときに字下げを補って入れ子として表示する。
