### 4. 四角形の当たり判定（isHit）

2 つの四角形 a と b が重なっているかは、次の 4 つの条件で調べられる。4 つが**すべて** `true` のとき、重なっている。

| 条件 | 意味 |
|---|---|
| `a.x < b.x + b.w` | a の左端が、b の右端より左にある |
| `a.x + a.w > b.x` | a の右端が、b の左端より右にある |
| `a.y < b.y + b.h` | a の上端が、b の下端より上にある |
| `a.y + a.h > b.y` | a の下端が、b の上端より下にある |

```
重なっている例                     重なっていない例（a が b より左にある）

   ┌───a───┐                        ┌──a──┐   ┌──b──┐
   │   ┌───┼───┐                    │     │   │     │
   └───┼───┘   │                    └─────┘   └─────┘
       └───b───┘                    a.x + a.w > b.x が false になる
```

- 1 つでも `false` になれば、横か縦のどちらかで離れているので、重なっていない。

「更新」の部分の `updateEnemies` の下に、`isHit` を追加する。

```javascript
// 2 つの四角形が重なっていたら true を返す
function isHit(a, b) {
  return a.x < b.x + b.w && a.x + a.w > b.x && a.y < b.y + b.h && a.y + a.h > b.y;
}
```

- 第 20 回で学んだ「真偽値を返す関数」。引数 `a` と `b` に、`x`・`y`・`w`・`h` を持つオブジェクトを渡す。
- 弾も敵も自機も、同じ `{ x, y, w, h }` の形なので、どの組み合わせにも同じ `isHit` が使える。

### 5. for の中の for（入れ子）と break

すべての弾と、すべての敵の組み合わせを調べるには、`for` の中に `for` を書く（`for` の入れ子）。

「更新」の部分の `isHit` の下に、`checkBulletHits` を追加する。

```javascript
// 弾と敵の当たり判定
function checkBulletHits() {
  for (let i = bullets.length - 1; i >= 0; i--) {
    for (let j = enemies.length - 1; j >= 0; j--) {
      if (isHit(bullets[i], enemies[j])) {
        bullets.splice(i, 1);
        enemies.splice(j, 1);
        score += 100;
        break;                   // この弾は消えたので、次の弾へ
      }
    }
  }
}
```

**(1) for の入れ子**

- 外側の `for`（`i`）で弾を 1 つ選び、内側の `for`（`j`）で、その弾とすべての敵を比べる。
- 内側の `for` が最後まで終わると、外側の `i` が 1 つ進み、次の弾で、また全部の敵と比べる。
- 内側と外側で、別の変数名（`i` と `j`）を使う。同じ名前にすると、正しく数えられない。

| 弾 `i` | 比べる敵 `j` |
|---|---|
| 弾 2 | 敵 1、敵 0 |
| 弾 1 | 敵 1、敵 0 |
| 弾 0 | 敵 1、敵 0 |

（弾 3 発・敵 2 体のとき。どちらも削除があるので、後ろから調べる。）

**(2) 当たったとき**

- 弾と敵の両方を `splice` で消し、得点を 100 増やす。

**(3) break**

- `break;`：その `for` 文を、途中で終わらせる。`for` が入れ子のときは、`break` を書いた内側の `for` だけが終わる。
- 弾 `i` は、当たった時点で消えている。そのまま内側の `for` を続けると、消えた弾（`bullets[i]`）を調べようとして、エラーになることがある。
- そこで `break` で内側の `for` を終わらせ、外側の `for` で次の弾へ進む。
