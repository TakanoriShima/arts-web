### 3. 第 20 回のクリックと、今回のキー入力

第 20 回では、ボタンがクリックされたら関数を呼び出した。

```
scoreButton.addEventListener("click", addTenPoints);
```

今回は、キーが押されたら処理をする。書き方は次のようになる。

```
document.addEventListener("keydown", function (event) {
  キーが押されたときに実行する処理
});
```

「イベント（出来事）が起きたら、関数を呼び出す」という考え方は、第 20 回と同じ。違うのは次の 3 点。

| | 第 20 回（クリック） | 今回（キー入力） |
|---|---|---|
| どこで待つか | ボタン（`scoreButton`） | ページ全体（`document`） |
| 何を待つか | `"click"` | `"keydown"`（キーが押された）、`"keyup"`（キーが離された） |
| 呼び出す関数 | 名前のある関数（`addTenPoints`） | その場で書く、**名前のない関数** `function (event) { }` |

- `function (event) { }` は、名前のない関数。そこでしか使わない関数なので、名前を付けずに、その場で作って `addEventListener` に渡している。
- イベントが起きるたびに、ブラウザがこの関数を呼び出す。そのとき、引数 `event` に、イベントの情報が入る。
- 今回は、`event` の中の `event.key`（押されたキーの名前）だけを使う。

| キー | `event.key` の値 |
|---|---|
| `←` `→` `↑` `↓` | `"ArrowLeft"` `"ArrowRight"` `"ArrowUp"` `"ArrowDown"` |
| スペース | `" "`（空白 1 文字） |
| `A` | `"a"`（Shift を押しながらだと `"A"`） |

### 4. キーの状態を変数に記録する

「自機」の部分の下に、「キー入力」の部分を追加する。

```javascript
// ===== キー入力 =====
let isLeftPressed = false;
let isRightPressed = false;

document.addEventListener("keydown", function (event) {
  console.log(event.key);        // 押したキーの名前を確認する
  if (event.key === "ArrowLeft") {
    isLeftPressed = true;
  }
  if (event.key === "ArrowRight") {
    isRightPressed = true;
  }
});

document.addEventListener("keyup", function (event) {
  if (event.key === "ArrowLeft") {
    isLeftPressed = false;
  }
  if (event.key === "ArrowRight") {
    isRightPressed = false;
  }
});
```

- `isLeftPressed`：`←` キーが押されている間は `true`、離すと `false` になる。
- キーを押したときに自機を直接動かすのではなく、「押されているかどうか」だけを変数に記録する。実際に動かすのは、ゲームループの `updatePlayer` で行う。
  - こうすると、キーを押している間、毎フレームなめらかに動き続ける。
- `console.log(event.key);` で、押したキーの名前がコンソールに表示される。いろいろなキーを押して確認する（この行は、次回、書き換えるときに消す）。

### 5. updatePlayer を書き換える

「更新」の部分の `updatePlayer` を、次のように書き換える（第 22 回の「右端から出たら左端に戻す」処理は消す）。

```javascript
function updatePlayer() {
  if (isLeftPressed) {
    player.x -= player.speed;
  }
  if (isRightPressed) {
    player.x += player.speed;
  }
  // 画面の端で止める
  if (player.x < 0) {
    player.x = 0;
  }
  if (player.x + player.w > canvas.width) {
    player.x = canvas.width - player.w;
  }
}
```

- `←` が押されていれば左へ、`→` が押されていれば右へ、`speed` だけ動かす。
- 第 18 回で学んだ「画面の端で止める」処理。右端は、自機の右端（`player.x + player.w`）で比べる。

### 6. うまく動かないとき

| 症状 | 確認すること |
|---|---|
| キーを押しても動かない | 画面を一度クリックしたか。`"ArrowLeft"` の綴り（大文字・小文字）。コンソールに `event.key` が出ているか |
| 離しても止まらない | `keyup` のほうで `false` に戻しているか。キーを押したままブラウザの外をクリックした場合は、画面をクリックしてから、同じキーをもう一度押して離す |
| 画面の外に出る | 端で止める `if` があるか。右端は `player.w` を足して比べているか |

## この回の終わりの `sample/main.js` 全体

```javascript
// ===== 準備 =====
const canvas = document.getElementById("game");
const ctx = canvas.getContext("2d");

// ===== ゲームの状態 =====
let frameCount = 0;              // ゲーム開始からのフレーム数

// ===== 自機 =====
const player = { x: 184, y: 440, w: 32, h: 32, speed: 5 };

// ===== キー入力 =====
let isLeftPressed = false;
let isRightPressed = false;

document.addEventListener("keydown", function (event) {
  console.log(event.key);        // 押したキーの名前を確認する
  if (event.key === "ArrowLeft") {
    isLeftPressed = true;
  }
  if (event.key === "ArrowRight") {
    isRightPressed = true;
  }
});

document.addEventListener("keyup", function (event) {
  if (event.key === "ArrowLeft") {
    isLeftPressed = false;
  }
  if (event.key === "ArrowRight") {
    isRightPressed = false;
  }
});

// ===== 更新 =====
function updatePlayer() {
  if (isLeftPressed) {
    player.x -= player.speed;
  }
  if (isRightPressed) {
    player.x += player.speed;
  }
  // 画面の端で止める
  if (player.x < 0) {
    player.x = 0;
  }
  if (player.x + player.w > canvas.width) {
    player.x = canvas.width - player.w;
  }
}

function update() {
  frameCount += 1;
  updatePlayer();
}

// ===== 描画 =====
function drawBackground() {
  ctx.fillStyle = "#000022";
  ctx.fillRect(0, 0, canvas.width, canvas.height);
}

function drawPlayer() {
  ctx.fillStyle = "#00ccff";
  ctx.fillRect(player.x, player.y, player.w, player.h);
}

function draw() {
  drawBackground();
  drawPlayer();
}

// ===== ゲームループ =====
function gameLoop() {
  update();
  draw();
  requestAnimationFrame(gameLoop);
}

gameLoop();
```
