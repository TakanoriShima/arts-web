### 4. ゲームの状態（gameState）

ゲームには、「プレイ中」「ゲームオーバー」のような「状態」がある。状態によって、行う処理が変わる。

| 状態 | `gameState` の値 | 更新（動かす） | 描画 | パネル |
|---|---|---|---|---|
| プレイ中 | `"play"` | する | する | 隠す |
| ゲームオーバー | `"gameover"` | **しない**（止まる） | する | 表示する |

「ゲームの状態」の部分の先頭に追加する。

```javascript
// ===== ゲームの状態 =====
let gameState = "play";          // "play"：プレイ中　"gameover"：ゲームオーバー
let score = 0;
let lives = 3;
let frameCount = 0;              // ゲーム開始からのフレーム数
```

「ゲームループ」の部分の `gameLoop` を、次のように書き換える。

```javascript
// ===== ゲームループ =====
function gameLoop() {
  if (gameState === "play") {
    update();
  }
  draw();
  requestAnimationFrame(gameLoop);
}
```

- `gameState` が `"play"` のときだけ、`update` を呼び出す。ゲームオーバーになると、自機も弾も敵も止まる。
- `draw` と `requestAnimationFrame` は、状態に関係なく続ける。ゲームループそのものは止めない。

### 5. 残機 0 で GAME OVER にする（.show）

「更新」の部分の `checkPlayerHit` を、次のように書き換える（`if (lives <= 0)` の 5 行を追加する）。

```javascript
// 敵と自機の当たり判定
function checkPlayerHit() {
  for (let i = enemies.length - 1; i >= 0; i--) {
    if (isHit(player, enemies[i])) {
      enemies.splice(i, 1);
      lives -= 1;
      $("#lives").text(lives);
      if (lives <= 0) {
        gameState = "gameover";
        $("#finalScore").text(score);
        $("#gameOverPanel").show();
      }
      break;                     // 1 フレームで減る残機は 1 つまで
    }
  }
}
```

- 残機が 0 以下になったら、`gameState` を `"gameover"` にして、ゲームを止める。
- `$("#finalScore").text(score);`：パネルの最終得点に、今の得点を入れる（第 27 回の `.text( )`）。
- `$("#gameOverPanel").show();`：パネルを**表示する**。

| jQuery | すること |
|---|---|
| `$("#id").show();` | 要素を表示する |
| `$("#id").hide();` | 要素を隠す |

- `.show( )` と `.hide( )` は、対になる操作。今回は、ゲームオーバーで `.show( )`、リスタートで `.hide( )` を使う。

### 6. リスタート（resetGame と .on("click")）

リスタートするには、ゲームの途中で変わった変数を、最初の値に戻す。HTML の表示も戻し、パネルを隠す。「キー入力」の部分の下に、「リスタート」の部分を追加する。

```javascript
// ===== リスタート =====
function resetGame() {
  gameState = "play";
  score = 0;
  lives = 3;
  frameCount = 0;
  player.x = 184;
  bullets = [];
  enemies = [];
  shotTimer = 0;
  $("#score").text(score);
  $("#lives").text(lives);
  $("#gameOverPanel").hide();
}

$("#restartButton").on("click", resetGame);
```

- 前半の 8 行：変数を最初の値に戻す。`bullets = [];`・`enemies = [];` は、空の配列を代入し直して、画面の弾と敵をすべて消す（`bullets` と `enemies` を `let` で作ったのは、このため）。
- `$("#score").text(score);`・`$("#lives").text(lives);`：変数を戻しただけでは、HTML の表示は古いまま。表示も戻す。
- `$("#gameOverPanel").hide();`：パネルを**隠す**。
  - パネルを隠すと、リスタートボタンも一緒に隠れる。ボタンが選ばれた状態のまま残って、スペースキーを押したときにボタンがもう一度押される、ということも防げる。
- `$("#restartButton").on("click", resetGame);`：リスタートボタンがクリックされたら、`resetGame` を呼び出す。
  - 第 20 回の `scoreButton.addEventListener("click", addTenPoints);` と同じ考え方。jQuery では `.on("click", 関数名)` と書く。
  - 関数名に `( )` を付けない（関数そのものを渡す）のも、第 20 回と同じ。
- 最初の値は、ファイルの上の方と `resetGame` の 2 か所に書いてある。値を変えるときは、両方を変える。

### 7. うまく動かないとき

| 症状 | 確認すること |
|---|---|
| 最初からパネルが表示されている | `style.css` の `#gameOverPanel { display: none; }`。`index.html` で `style.css` を読み込んでいるか |
| 残機が 0 でも止まらない | `gameLoop` の `if (gameState === "play")`。`checkPlayerHit` で `gameState = "gameover";` にしているか |
| パネルが出ない | `$("#gameOverPanel")` の綴りと `#`。HTML の `id` と同じ名前か |
| ボタンを押しても何も起きない | `$("#restartButton").on("click", resetGame);` を書いたか。`resetGame()` と `( )` を付けていないか |
| リスタート後に敵や弾が残る、表示が戻らない | `resetGame` で戻し忘れている変数・表示がないか（次回、全体を確認する） |
