## 講義内容

### 1. 前回の復習

- `isHit(a, b)`：2 つの四角形が重なっていたら `true` を返す関数。
- `checkBulletHits`：`for` の入れ子で、すべての弾とすべての敵を比べる。当たったら両方を消して、得点を増やし、`break` で次の弾へ進む。

今回は、次の 2 つを行う。

- 敵が自機にぶつかったら、残機を 1 減らす。
- 得点と残機を、画面に表示する。

### 3. 残機の変数

「ゲームの状態」の部分に、`lives` を追加する。

```javascript
// ===== ゲームの状態 =====
let score = 0;
let lives = 3;
let frameCount = 0;              // ゲーム開始からのフレーム数
```

### 4. 敵と自機の当たり判定（checkPlayerHit）

「更新」の部分の `checkBulletHits` の下に、`checkPlayerHit` を追加する。

```javascript
// 敵と自機の当たり判定
function checkPlayerHit() {
  for (let i = enemies.length - 1; i >= 0; i--) {
    if (isHit(player, enemies[i])) {
      enemies.splice(i, 1);
      lives -= 1;
      break;                     // 1 フレームで減る残機は 1 つまで
    }
  }
}
```

- 前回作った `isHit` を、そのまま使い回している。`player` も `enemies[i]` も、`x`・`y`・`w`・`h` を持つオブジェクトなので、同じ関数で判定できる。
- 自機は 1 つなので、`for` は入れ子にならない。すべての敵と、自機を比べる。
- ぶつかった敵を消して、残機を 1 減らす。
- 敵が 2 体同時にぶつかっても、残機が一度に 2 つ減らないように、`break` で `for` を終わらせる。

「更新」の部分の `update` を、次のようにする。

```javascript
function update() {
  frameCount += 1;
  updatePlayer();
  updateBullets();
  updateEnemies();
  checkBulletHits();
  checkPlayerHit();
}
```

### 5. 得点と残機を表示する（drawUI）

「描画」の部分の `drawUI` を、次のように書き換える。第 22 回から表示していた `FRAME`・`BULLETS`・`ENEMIES` は、動作確認のための表示だったので、ここで消す。

```javascript
function drawUI() {
  ctx.fillStyle = "#ffffff";
  ctx.font = "20px sans-serif";
  ctx.textAlign = "left";
  ctx.fillText(`SCORE: ${score}`, 10, 30);
  ctx.fillText(`LIVES: ${lives}`, 10, 60);
}
```

- `fillText` の文字の部分に、テンプレートリテラルを使っている。`${score}` の部分に、そのときの得点が入る。
- `drawUI` は毎フレーム呼び出されるので、得点や残機が変わると、すぐに表示も変わる。
- `drawUI` は、`draw` の最後に呼び出している。最後に描くので、文字が敵や弾の下に隠れない。
- `ctx.textAlign = "left";` は、次回、別の場所で `"center"` に変えるため、ここで毎回 `"left"` に戻している。

### 6. 確認

- 敵を倒すと、`SCORE` が 100 ずつ増える。
- 敵にぶつかると、敵が消えて、`LIVES` が 1 減る。
- 今は、残機が 0 になってもゲームが続き、`LIVES` がマイナスになる。ゲームオーバーは、次回作る。
