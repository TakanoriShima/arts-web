## 講義内容

| キー | 動作 |
|---|---|

| `Enter` | ゲームオーバーのあとに、リスタートする |

### 2. プログラムの全体の流れ

ゲームは、`gameLoop` を 1 秒間に約 60 回くり返して動いている。1 回ごとに「更新（`update`）→ 描画（`draw`）」を行う。

```
gameLoop
├─ プレイ中なら update（動かす・当たり判定）
│   ├─ updatePlayer      自機を動かす
│   ├─ updateBullets     弾を撃つ・動かす・画面外で消す
│   ├─ updateEnemies     敵を出す・動かす・画面外で消す
│   ├─ checkBulletHits   弾と敵の当たり判定
│   └─ checkPlayerHit    敵と自機の当たり判定
├─ draw（描く）
│   └─ 背景 → 自機 → 弾 → 敵 → 得点・残機（→ ゲームオーバーの文字）
└─ requestAnimationFrame(gameLoop)   次の回を予約する
```

- `gameState` が `"play"` の間だけ `update` を行う。`"gameover"` になると、動きが止まり、描画だけが続く。

### 3. 完成版のコード

`sample/main.js` の内容を、上から順に確認する。つなげると、`sample/main.js` 全体になる。

#### (1) 準備と変数（仕様 1）

```javascript
// ===== 準備 =====
const canvas = document.getElementById("game");
const ctx = canvas.getContext("2d");

// ===== ゲームの状態 =====
let gameState = "play";          // "play"：プレイ中　"gameover"：ゲームオーバー
let score = 0;
let lives = 3;
let frameCount = 0;              // ゲーム開始からのフレーム数

// ===== 自機・弾・敵 =====
const player = { x: 184, y: 440, w: 32, h: 32, speed: 5 };
let bullets = [];
let enemies = [];
let shotTimer = 0;               // 次の弾を撃てるまでのフレーム数
```

- 得点（`score`）、残機（`lives`）、状態（`gameState`）は、ゲーム全体で使うので、ファイルの先頭で用意する。
- 自機・弾・敵は、`{ x, y, w, h }`（位置と大きさ）を持つオブジェクトで表す。弾と敵は数が変わるので、配列に入れる。

#### (2) キー入力（仕様 2・3・9）

```javascript
// ===== キー入力 =====
let isLeftPressed = false;
let isRightPressed = false;
let isSpacePressed = false;

document.addEventListener("keydown", function (event) {
  if (event.key === "ArrowLeft") {
    isLeftPressed = true;
  }
  if (event.key === "ArrowRight") {
    isRightPressed = true;
  }
  if (event.key === " ") {
    isSpacePressed = true;
  }
  if (event.key === "Enter" && gameState === "gameover") {
    resetGame();
  }
});

document.addEventListener("keyup", function (event) {
  if (event.key === "ArrowLeft") {
    isLeftPressed = false;
  }
  if (event.key === "ArrowRight") {
    isRightPressed = false;
  }
  if (event.key === " ") {
    isSpacePressed = false;
  }
});
```

- キーを押したときに `true`、離したときに `false` にしておき、実際の移動や発射は `update` の中で行う。
- `Enter` キーは、ゲームオーバーのときだけリスタートする（`&&` で 2 つの条件をつなげている）。

#### (3) リスタート（仕様 9）

```javascript
// ===== リスタート =====
function resetGame() {
  gameState = "play";
  score = 0;
  lives = 3;
  frameCount = 0;
  player.x = 184;
  bullets = [];
  enemies = [];
  shotTimer = 0;
}
```

- ゲームの途中で変わる変数を、**すべて**最初の値に戻す。戻し忘れると、リスタート後に前のゲームの敵や得点が残る。
- 最初の値は、ファイルの先頭と `resetGame` の 2 か所に書いてある。値を変えるときは、両方を変える。

#### (4) 自機・弾・敵を動かす（仕様 2・3・4）

```javascript
// ===== 更新 =====
function updatePlayer() {
  if (isLeftPressed) {
    player.x -= player.speed;
  }
  if (isRightPressed) {
    player.x += player.speed;
  }
  // 画面の端で止める
  if (player.x < 0) {
    player.x = 0;
  }
  if (player.x + player.w > canvas.width) {
    player.x = canvas.width - player.w;
  }
}
```

- 第 18 回で学んだ「画面の端で止める」処理。右端は、`player.x + player.w`（自機の右端）で比べる。

```javascript
function updateBullets() {
  if (shotTimer > 0) {
    shotTimer -= 1;
  }
  // スペースキーを押していて、撃てる状態なら、弾を追加する
  if (isSpacePressed && shotTimer === 0) {
    bullets.push({ x: player.x + player.w / 2 - 2, y: player.y, w: 4, h: 12, speed: 8 });
    shotTimer = 10;
  }
  for (let i = bullets.length - 1; i >= 0; i--) {
    bullets[i].y -= bullets[i].speed;
    // 画面の上に出た弾を消す
    if (bullets[i].y + bullets[i].h < 0) {
      bullets.splice(i, 1);
    }
  }
}
```

- `shotTimer` は、次の弾を撃てるまでの待ち時間。弾を撃つと 10 になり、1 フレームごとに 1 ずつ減る。0 になると、また撃てる。
- 弾の `x` は、自機の中央（`player.x + player.w / 2`）から、弾の幅の半分（2）を引いた位置にする。

```javascript
function updateEnemies() {
  // 60 フレーム（約 1 秒）ごとに、敵を 1 体出す
  if (frameCount % 60 === 0) {
    enemies.push({ x: Math.floor(Math.random() * (canvas.width - 32)), y: -32, w: 32, h: 32, speed: 2 });
  }
  for (let i = enemies.length - 1; i >= 0; i--) {
    enemies[i].y += enemies[i].speed;
    // 画面の下に出た敵を消す
    if (enemies[i].y > canvas.height) {
      enemies.splice(i, 1);
    }
  }
}
```

- `frameCount % 60 === 0` は、「フレーム数が 60 で割り切れるとき」、つまり 60 フレームに 1 回。
- 出現位置の `x` は、第 18 回の「`Math.floor(Math.random() * 個数) + 最小値`」の形。敵が画面の右からはみ出さないように、`canvas.width - 32`（敵の幅を引いた値）を使う。
- 配列から `splice` で消すときは、配列の**後ろから**順に調べる。前から調べると、消した後ろの要素が 1 つ前に詰まり、調べずに飛ばしてしまう要素が出る。

#### (5) 当たり判定（仕様 5・6・7・8）

```javascript
// 2 つの四角形が重なっていたら true を返す
function isHit(a, b) {
  return a.x < b.x + b.w && a.x + a.w > b.x && a.y < b.y + b.h && a.y + a.h > b.y;
}

// 弾と敵の当たり判定
function checkBulletHits() {
  for (let i = bullets.length - 1; i >= 0; i--) {
    for (let j = enemies.length - 1; j >= 0; j--) {
      if (isHit(bullets[i], enemies[j])) {
        bullets.splice(i, 1);
        enemies.splice(j, 1);
        score += 100;
        break;                   // この弾は消えたので、次の弾へ
      }
    }
  }
}
```

- `isHit` は、2 つの四角形が重なっているかを調べる。4 つの条件が**すべて** `true` のとき、重なっている。
- 当たったら、弾と敵を両方とも配列から消し、得点を増やす。

```javascript
// 敵と自機の当たり判定
function checkPlayerHit() {
  for (let i = enemies.length - 1; i >= 0; i--) {
    if (isHit(player, enemies[i])) {
      enemies.splice(i, 1);
      lives -= 1;
      if (lives <= 0) {
        gameState = "gameover";
      }
      break;                     // 1 フレームで減る残機は 1 つまで
    }
  }
}
```

- 敵に当たったら、その敵を消して、残機を 1 減らす。残機が 0 以下になったら、`gameState` を `"gameover"` にする。

```javascript
function update() {
  frameCount += 1;
  updatePlayer();
  updateBullets();
  updateEnemies();
  checkBulletHits();
  checkPlayerHit();
}
```

- `update` は、更新の処理をまとめて呼び出す。当たり判定は、全員を動かしたあとに行う。

#### (6) 描画（仕様 1・6・7・8）

```javascript
// ===== 描画 =====
function drawBackground() {
  ctx.fillStyle = "#000022";
  ctx.fillRect(0, 0, canvas.width, canvas.height);
}

function drawPlayer() {
  ctx.fillStyle = "#00ccff";
  ctx.fillRect(player.x, player.y, player.w, player.h);
}

function drawBullets() {
  ctx.fillStyle = "#ffff00";
  for (let i = 0; i < bullets.length; i++) {
    ctx.fillRect(bullets[i].x, bullets[i].y, bullets[i].w, bullets[i].h);
  }
}

function drawEnemies() {
  ctx.fillStyle = "#ff4444";
  for (let i = 0; i < enemies.length; i++) {
    ctx.fillRect(enemies[i].x, enemies[i].y, enemies[i].w, enemies[i].h);
  }
}
```

```javascript
function drawUI() {
  ctx.fillStyle = "#ffffff";
  ctx.font = "20px sans-serif";
  ctx.textAlign = "left";
  ctx.fillText(`SCORE: ${score}`, 10, 30);
  ctx.fillText(`LIVES: ${lives}`, 10, 60);
}

function drawGameOver() {
  ctx.fillStyle = "#ffffff";
  ctx.textAlign = "center";
  ctx.font = "40px sans-serif";
  ctx.fillText("GAME OVER", canvas.width / 2, 230);
  ctx.font = "20px sans-serif";
  ctx.fillText("Enter キーでリスタート", canvas.width / 2, 280);
}

function draw() {
  drawBackground();
  drawPlayer();
  drawBullets();
  drawEnemies();
  drawUI();
  if (gameState === "gameover") {
    drawGameOver();
  }
}
```

- 描いた順に上へ重なる。最初に背景を描き、文字は最後に描く。
- 得点・残機は、テンプレートリテラルで `fillText` に渡している。

#### (7) ゲームループ

```javascript
// ===== ゲームループ =====
function gameLoop() {
  if (gameState === "play") {
    update();
  }
  draw();
  requestAnimationFrame(gameLoop);
}

gameLoop();
```

- 最後の `gameLoop();` で、ゲームが始まる。

### 4. 完成前の確認

次の表で、うまく動かないときの確認場所を探す。まず `F12` の開発者ツール（コンソール）で、赤字のエラーが出ていないかを見る。

| 症状 | 確認すること |
|---|---|
| 画面に何も表示されない | コンソールのエラー。`getElementById` の `id` と、`<canvas>` の `id` が同じか |
| 自機が動かない | `event.key` の綴り（`"ArrowLeft"`、`"ArrowRight"`）。大文字・小文字も同じか |
| 自機が画面の外に出る | 画面の端で止める `if` 文があるか。右端は `player.w` を足して比べているか |
| 弾・敵が出ない | `push` しているか。`draw` から `drawBullets`・`drawEnemies` を呼び出しているか |
| 当たっても敵が消えない | `update` から `checkBulletHits` を呼び出しているか。`isHit` の 4 つの条件 |
| リスタート後に敵や得点が残る | `resetGame` で、配列を `[]` に、得点・残機を最初の値に戻しているか |
