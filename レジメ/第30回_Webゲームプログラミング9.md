## 講義内容

### 1. 最終ゲームの役割分担

完成したゲームは、5 つの技術がそれぞれの仕事を分担している。

| 担当 | 役割 | 学んだ回 |
|---|---|---|
| HTML（`index.html`） | キャンバス、SCORE・LIVES の表示欄、GAME OVER のパネル、最終得点、リスタートボタン | 第 20・26〜28 回 |
| CSS（`style.css`） | ページの余白・スクロール、パネルを最初は隠す | 第 22・28 回 |
| Canvas | 背景・自機・弾・敵など、動くものを描く | 第 21〜25 回 |
| JavaScript | ゲームの状態、ゲームループ、キー入力、移動、配列の管理、当たり判定 | 第 22〜28 回 |
| jQuery | SCORE・LIVES・最終得点の表示、パネルの表示・非表示、リスタートボタンのクリック | 第 27・28 回 |

- 得点や GAME OVER などの文字は、Canvas ではなく HTML に表示している。Canvas には、動くものだけを描く。

### 2. ゲームの 1 フレームの流れ

```
gameLoop（1 秒に約 60 回）
├─ プレイ中なら update（動かす・消す・当たり判定）
│   ├─ updatePlayer      自機を動かす（キー入力の変数を見る）
│   ├─ updateBullets     弾を撃つ・動かす
│   ├─ updateEnemies     敵を出す・動かす
│   ├─ removeEnemies     画面外の敵を消す
│   ├─ removeBullets     画面外の弾を消す
│   ├─ checkBulletHits   弾と敵の当たり判定 → 得点を増やし、jQuery で表示
│   └─ checkPlayerHit    敵と自機の当たり判定 → 残機を減らし、jQuery で表示 → 0 なら GAME OVER
├─ draw（背景 → 自機 → 弾 → 敵 を Canvas に描く）
└─ requestAnimationFrame(gameLoop)

リスタートボタンのクリック → resetGame（変数・表示を戻し、パネルを隠す）
```

### 3. 最終必須仕様のチェックリスト

自分のゲームで、1 つずつ確かめる。できていない項目は、「見直す回」のレジメと `sample` を見て直す。

| No. | 必須仕様 | 確認方法 | 関係する関数・場所 | 見直す回 |
|---|---|---|---|---|
| 1 | Canvas に自機を表示 | ページを開くと、自機が見える | `player`、`drawPlayer`、`draw` | 第 21・22 回 |
| 2 | キーで自機を移動 | `←` `→` で左右に動き、画面の端で止まる | キー入力、`updatePlayer` | 第 23 回 |
| 3 | キーで弾を発射 | スペースキーで弾が出て、上へ飛ぶ | `updateBullets`、`drawBullets` | 第 24 回 |
| 4 | 敵が出現・移動 | 敵が上から出て、下へ動く。コンソールで `bullets.length`・`enemies.length` が増え続けない | `updateEnemies`、`drawEnemies`、`removeEnemies`、`removeBullets` | 第 25 回 |
| 5 | 弾と敵の当たり判定 | 弾が敵に重なると、反応する | `isHit`、`checkBulletHits` | 第 26 回 |
| 6 | 敵が消え、得点が増える | 当たった弾と敵が消え、SCORE が増える | `checkBulletHits` | 第 26 回 |
| 7 | 接触で残機が減る | 敵にぶつかると、敵が消えて LIVES が減る | `checkPlayerHit` | 第 27 回 |
| 8 | 得点・残機を HTML に表示し、jQuery で更新 | SCORE・LIVES が HTML の文字として表示され、変わる。`$("#score").text(...)` などで更新している | `index.html` の表示欄、`checkBulletHits`、`checkPlayerHit` | 第 26・27 回 |
| 9 | 残機 0 でゲームオーバーパネル | 残機 0 でゲームが止まり、GAME OVER のパネルと最終得点が出る | `checkPlayerHit`、`gameLoop`、`index.html` のパネル、`style.css` | 第 28 回 |
| 10 | リスタートボタンで再開 | ボタンを押すと、得点・残機・自機が最初に戻り、弾と敵が消え、パネルが消えて、また遊べる | `resetGame`、`.on("click", resetGame)` | 第 28・29 回 |

- 最後に、ゲームを始めてからゲームオーバー、リスタートまで、コンソールに赤字のエラーが出ないことを確かめる。

### 4. うまく動かないとき

| 症状 | 確認すること | 見直す回 |
|---|---|---|
| 何も表示されない | コンソールのエラー。`getElementById("game")` と `<canvas>` の `id` | 第 21・29 回 |
| 自機が動かない | `event.key` の綴り（`"ArrowLeft"`）。画面を一度クリックしたか | 第 23 回 |
| 弾・敵が出ない | `update` から呼んでいるか。`push` しているか | 第 24・25 回 |
| 当たっても消えない | `update` から `checkBulletHits` を呼んでいるか。`isHit` の条件 | 第 26 回 |
| `$ is not defined` | jQuery の `<script>` が `main.js` より前にあるか。インターネットの接続 | 第 27 回 |
| SCORE・LIVES が変わらない | `$("#score")` の `#`、HTML の `id` と同じ名前か | 第 27・29 回 |
| パネルが出ない・最初から出ている | `style.css` の `display: none;`、`.show()`・`.hide()` | 第 28 回 |
| リスタート後に何かが残る | `resetGame` の戻し忘れ（変数と表示） | 第 29 回 |

### 演習２　遊びやすさを調整する

- 次の中から 3 つ以上を選んで値を変え、遊びやすさ（難しさ）を自分で調整する。

| 調整する値 | 場所 |
|---|---|
| 自機の速さ | `player` の `speed` |

### 発展（任意）

これまでに学んだことだけで作れるもの。

- **Enter キーでリスタート**：ゲームオーバーのときだけ、`Enter` キーでも `resetGame` を呼ぶ（第 23・28 回）。
- **ハイスコア**：HTML に `HIGH SCORE: <span id="highScore">0</span>` を追加する。ゲームオーバーのとき、得点がハイスコアより大きければ、ハイスコアを更新して jQuery で表示する。リスタートしても、ハイスコアは戻さない。
- **タイトル画面**：HTML にタイトルのパネル（ゲーム名、操作方法、スタートボタン）を作る。`gameState` を最初は `"title"` にしてゲームを止めておき、スタートボタンの `.on("click", resetGame)` で始める。`resetGame` の中で、タイトルのパネルも `.hide()` で隠す。
- **難易度**：得点が増えるほど、敵の出現間隔を短く、敵を速くする（出現間隔と速さを変数にして、得点から計算する。第 18 回の「上限で止める」`if` で、速くなりすぎないようにする）。
