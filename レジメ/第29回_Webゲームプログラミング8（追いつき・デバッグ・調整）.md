### 2. うまく動かないときの調べ方

#### (1) コンソールのエラーを読む

`F12` の開発者ツールのコンソールに、赤字でエラーが表示される。エラーの右側には、エラーが起きたファイル名と行番号（例：`main.js:85`）が表示される。まず、その行を見る。

| エラーの表示（一部） | 主な原因 |
|---|---|
| `ReferenceError: ○○ is not defined` | 変数名・関数名の綴りの間違い。作っていない変数や関数を使っている |
| `ReferenceError: $ is not defined` | jQuery を読み込んでいない。jQuery の `<script>` が `main.js` より後ろにある。インターネットにつながっていない |
| `TypeError: Cannot read properties of undefined (reading 'y')` | 配列のない番号（`bullets[5]` など）の `.y` を使おうとした。`for` の条件が `<=` になっている、`break` を忘れた、など |
| `TypeError: Cannot read properties of null (reading 'getContext')` | `getElementById("game")` の名前と、`<canvas>` の `id` が違う |
| `SyntaxError: Unexpected token '}'` | `{ }` や `( )` の数が合っていない。`,` や `;` の書き忘れ・書きすぎ |

- エラーが 1 つ出ると、そこから先の処理が実行されないことがある。上に表示されたエラーから順に直す。

#### (2) エラーが出ないのに、思いどおりに動かないとき

- **コンソールに変数名を入力する**：`score`、`lives`、`gameState`、`bullets.length`、`enemies.length` などを入力して `Enter` キーを押すと、その時点の値が分かる。
- **`console.log` を一時的に書く**：たとえば、`checkBulletHits` の `score += 100;` の下に `console.log(score);` を一時的に書くと、当たるたびに得点が表示される。確認したら、その行は消す。`update` の最初などに書くと、1 秒に 60 回表示されて読めなくなるので、`if` の中など、たまにしか実行されない場所に書く。
- **1 行ずつ `//` で止めてみる**：あやしい行の先頭に `//` を付けて、動きがどう変わるかを見る。
- **キーを離しても自機が止まらないとき**：キーを押したままブラウザの外をクリックすると、キーを離したこと（`keyup`）が伝わらず、自機が動き続けることがある。ゲームの画面をクリックしてから、同じキーをもう一度押して離すと止まる。

#### (3) HTML・CSS・JavaScript・jQuery のつながりを確かめる

表示に関係する名前は、3 つのファイルで同じにする必要がある。

| HTML（`index.html`） | CSS（`style.css`） | JavaScript（`main.js`） |
|---|---|---|
| `<span id="score">` | | `$("#score")` |
| `<span id="lives">` | | `$("#lives")` |
| `<div id="gameOverPanel">` | `#gameOverPanel { display: none; }` | `$("#gameOverPanel").show()`・`.hide()` |
| `<span id="finalScore">` | | `$("#finalScore")` |
| `<button id="restartButton">` | | `$("#restartButton").on("click", resetGame)` |
| `<canvas id="game">` | | `document.getElementById("game")` |

- jQuery では、`id` の前に `#` を付ける。付け忘れると、エラーは出ないが、表示が変わらない。

### 3. resetGame の確認

第 28 回で作った `resetGame` に戻し忘れがないかを、実際にゲームオーバー → リスタートして確かめる。

| 確認すること | 確かめ方 |
|---|---|
| 得点は 0 に戻ったか | 画面の SCORE、コンソールの `score` |
| 残機は最初の数に戻ったか | 画面の LIVES、コンソールの `lives` |
| 弾・敵は残っていないか | 画面、コンソールの `bullets.length`・`enemies.length` |
| 自機は最初の位置に戻ったか | 画面 |
| HTML の表示も戻ったか | SCORE・LIVES の数字（変数だけ戻して、表示を戻し忘れていないか） |
| パネルは消えたか | 画面、`resetGame` の `$("#gameOverPanel").hide();` |
| もう一度遊べるか | 自機が動き、弾が出て、敵が出るか（`gameState` を `"play"` に戻したか） |

### 4. 遊びやすさと見た目の調整

- **遊びやすさ**：自機の速さ（`player.speed`）、連射の間隔（`shotTimer = 10;`）、敵の出現間隔（`frameCount % 60`）、敵の速さ（`speed: 2`）、残機の数など。値を少しずつ変えて、遊んで確かめる。残機の数を変えるときは、ファイルの上の方と `resetGame`、`index.html` の最初の表示の 3 か所を変える。
- **色**：`ctx.fillStyle` には、CSS と同じ書き方で色を指定する（`#rrggbb` など）。背景を暗い色にして、自機・弾・敵を明るい色にすると見やすい。自機と敵は、はっきり違う色にする。
